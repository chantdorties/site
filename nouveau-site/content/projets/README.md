# Projets

Les livres à paraître, créés dans l’administration, sont enregistrés ici. Ils s’affichent
sur la page Projets, sous son texte d’introduction, du plus petit rang au plus grand.

Un intervenant qui possède déjà une fiche se choisit dans « Auteurs » ou « Illustrateurs »
et son nom devient un lien ; celui qui n’en a pas encore s’écrit à la main dans le champ
« sans fiche » voisin. Le jour où sa fiche existe, il suffit de basculer le nom de l’un à
l’autre.
